## Overview

This project contains the HTML5 version of the StudentHub website. Existing HTML pages were updated to use HTML5 semantic elements, improving structure, readability, accessibility, and maintainability.

## Objective

Convert the existing StudentHub pages to HTML5 by:

* Using semantic HTML5 elements.
* Maintaining a consistent page structure.
* Improving accessibility.
* Organizing content with meaningful tags.

## Pages Included

* Home (`index.html`)
* About (`about.html`)
* Register (`register.html`)
* Login (`login.html`)
* Dashboard (`dashboard.html`)
* Events (`events.html`)
* Profile (`profile.html`)
* Contact (`contact.html`)
* Admin (`admin.html`)
* FAQ (`faq.html`)
* Feedback (`feedback.html`)

## HTML5 Semantic Elements Used

* `<header>`
* `<nav>`
* `<main>`
* `<section>`
* `<article>`
* `<aside>`
* `<footer>`

## Accessibility Features

* Semantic page landmarks
* Proper heading hierarchy
* Labels for form inputs
* Meaningful navigation structure
* Responsive viewport meta tag
* Descriptive page titles
